# PaperFlow · 本地优先的文献管理器

PDF / EPUB 阅读与管理 · 中文全文搜索 · 知识图谱 · 艾宾浩斯记忆复习 · OCR · 收件箱自动导入

## 下载

前往 [**Releases**](https://github.com/luzhijintou/paperflow/releases/latest) 下载 `PaperFlow-win64-*.zip`：

1. 解压到任意位置
2. 双击 `PaperFlow.exe`（若 SmartScreen 提示，点「更多信息 → 仍要运行」，软件未做代码签名）
3. 无需安装，数据 100% 保存在本地；卸载只需删除文件夹

系统要求：Windows 10 / 11（64 位）

## 特点

- **本地优先** — 文档、笔记、阅读进度全部存本机（SQLite + 原文件），不上传任何数据
- **中文友好** — jieba 分词全文搜索，标题 / 作者 / 全文检索，支持中文界面与英文界面切换
- **知识图谱** — 文档间相似度自动建边，Obsidian 风格交互式图谱
- **间隔重复** — 艾宾浩斯按天复习排程（1 / 2 / 4 / 7 / 15 / 30 天阶梯），对抗遗忘曲线
- **OCR** — 扫描版 PDF 一键安装本地识别组件，识别文字并纳入搜索
- **收件箱** — 监听指定文件夹，文件放入即自动导入文档库
- **批量整理** — 集合 / 标签 / 相似查重 / 导出
